## 注释风格指南

### 1. 合约级别注释
```solidity
/// @title ContractName
/// @notice 合约的整体功能和用途
/// 
/// 详细说明：
/// - 主要功能点 1
/// - 主要功能点 2
/// - 安全机制说明
contract ContractName {
```

### 2. 函数级别注释
```solidity
/// @notice 函数功能简要说明
/// 
/// 详细流程说明：
/// 1. 步骤 1
/// 2. 步骤 2
/// 3. 步骤 3
/// 
/// 重要说明：
/// - 安全考虑
/// - 边界情况
/// 
/// @param _param 参数说明
/// @return 返回值说明
function functionName(...) {
```

### 3. 数据结构注释
```solidity
/// @notice 数据结构用途说明
/// 
/// 字段说明：
/// - field1: 字段 1 的用途
/// - field2: 字段 2 的用途
struct DataStructure {
    ...
}
```

### 4. 关键代码块注释
```solidity
// 功能说明：这段代码的作用
// 为什么需要：解释为什么需要这个检查/操作
// 安全考虑：相关的安全机制
```

## 注释要点

1. **使用中文**：所有注释使用中文，便于学习
2. **详细说明**：不仅说明"是什么"，还要说明"为什么"
3. **流程说明**：对于复杂函数，说明完整的执行流程
4. **安全机制**：重点说明安全相关的检查和机制
5. **示例说明**：在适当的地方提供使用示例
